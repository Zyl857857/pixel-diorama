# 主体动画

## 从主题推导动作

- 先选一个能改变剪影的主动作，再设计力量从哪里传到哪里。例如骨龙低头收翼蓄势，接着抬颌、展翼，翼尖和尾椎晚半拍跟上。动作较大的姿态给足停留，收势放慢，让循环接回开场。
- 从静态姿态检查关节与构图。把支点放在肩、腕、铰链等真实连接处，为相邻部件建立父子关系。先调大部件，再加局部跟随。要表现物体脱离，可以将断开的部件放进独立组。
- 环境动效也要有可辨认的物理过程。火舌在各自根部伸缩和偏转。烟团从源头升起、扩张、随风漂移并消散。布料从悬挂处向末端依次折动。给每一组错开的相位和幅度。
- 事件要有先后和重量。碎片先松动，脱离后加速，触地轻跳后停下或隐入碎石。悬物从固定支点起摆，摆幅逐步减小。在《灰钟关》中用同一阵冲击引出落砖和迟半拍的吊灯摆动，保留静止城门作为参照。
- 用静止镜头检查开场、发力前、幅度最大和回落四个姿态。检查漂移、穿插、脚下接触和翼尖是否出画。再打开播放检查首尾接缝、拖动镜头、暂停与继续。导出预览时保留一轮完整动作。

## 配方字段

配置 `motion.groups`，再在希望驱动的形体上设置 `motion: "组名"`。组的 `pivot` 是静止姿态下的世界坐标。可给组设置 `parent`，父组写在子组之前。关键帧的 `at` 以秒为单位并严格递增，首帧为 0、末帧为 8。用 XYZ `rotation` 指定弧度，按 X、Y、Z 依次旋转，用 XYZ `shift` 指定位移。省略任一字段等同于三个分量都为零。默认在每对关键帧之间平滑起停，首尾保留静止姿态。可逐帧指定正值 XYZ `scale` 和 0 至 1 的 `opacity`，缺省为原尺寸、原透明度。

```json
{
  "motion": {
    "groups": [
      {
        "id": "lever",
        "pivot": [0, 1.2, 0],
        "keys": [
          {"at": 0},
          {"at": 2.1, "rotation": [0, 0, -0.38]},
          {"at": 4.8, "rotation": [0, 0, -0.38]},
          {"at": 8}
        ]
      }
    ]
  }
}
```

## 连续运动

布料、火舌、烟、落体和阻尼摆可以由脚本生成均匀采样的关键帧。为该组设置 `sampled: true`，每一段线性插值，速度变化交给生成的曲线。首尾姿态必须相同，可以从运动中途入场。粒子重生前后降到全透明，避免从尾端飞回发射点。

```js
const keys = Array.from({length:129}, (_,i) => {
  const at=i/16;
  const phase=2*Math.PI*(i%128)/128;
  const lift=.22*Math.sin(5*phase);
  return {at, scale:[1, 1+lift, 1], rotation:[0,0,.12*Math.sin(3*phase)]};
});
const flame = {id:'flame', pivot:[0,.2,0], sampled:true, keys};
```

在成品里播放一个完整的 8 秒循环，检查运行方向、触地点和循环接缝。需要导出视频或动图时再采集帧。动图建议 24 或 25 帧每秒，放大时保持像素边缘。

形体配方仍可和水面、粒子、自由探索同时使用。可走场景用静止几何作为碰撞边界。活动部件使用烘焙材质色阶，地面和局部灯光仍取配方中的固定位置。可用 [骨龙苏醒配方](../assets/recipes/bone-dragon-awakens.json) 参考多级关节与错开的时序。静态预览取第 0 秒，HTML 加载后可播放循环，也遵循浏览器的减少动态效果设置。
